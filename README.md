# 平生功绩

以 CBDB 收录的 57,474 位唐代人物为线索，读籍贯、入仕与任职记录。地图看位置，排行方便比较；图旁保留人数、计数单位与分母，人物档案可继续回查编码与出处。

作者：**澹台枕流 / Unirevora**
## 数据范围

| 项目 | 人数或记录数 | 口径 |
| --- | ---: | --- |
| 唐代样本 | 57,474 人 | `BIOG_MAIN.c_dy = 6` |
| 有籍贯记录 | 28,245 人 | 按人物编号去重 |
| 有入仕记录 | 1,824 人 | 原始入仕记录 2,072 条 |
| 有官职记录 | 26,073 人 | 官职表 47,805 条 |
| 有有效任职地址 | 18,036 人 | 地点表 27,200 条 |

CBDB 将五代另列为 `c_dy = 7`，这里没有合并五代样本。整体分布反映资料收录情况，不能直接外推为历史总体；同名人物以编号区分，缺失记录保持空缺。

## GitHub 推送

本地保留一个 `push-github.cmd` 用于提交并推送网站。仓库固定为：

`https://github.com/Unirevora/PingshengGongji.git`

脚本会初始化或连接仓库、保留远端历史、提交当前改动并推送到 `main`；需要本机 Git 已有 GitHub 登录凭据。若远端已有新提交，会尝试 rebase，冲突时停止，保留现场供处理。不会强制推送。

没有既有 Git / 环境代理配置时，脚本会读取已启用的 Windows 系统代理，仅在本次运行使用；请保持代理软件运行。网络操作失败自动重试，最多三次。可运行 `push-github.cmd --check-network` 只检查 GitHub 连接，不提交或推送。

原始 SQLite、原始地图下载、课程报告、本机截图与旧测试材料留在本地，已从推送范围排除。网页、整理后的 JSON、字体、样式、交互与数据处理源码会提交。数据处理脚本是研究源码，不是本地启动入口。

## 文件

| --- | --- |
| `index.html` | 页面结构、正文与阅读入口 |

地图使用本地 Natural Earth 1:10m 地理层；在线层默认使用 Esri 地形，可切换 OSM 街道；加载失败或超过 8 秒未取得瓦片时回退本地纸本层。底图不表示唐代疆域，也不改变 CBDB 原始坐标精度。
