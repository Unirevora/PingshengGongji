# 平生功绩：数据方法与修订说明

本地数据库快照文件名：`cbdb_20260523.sqlite3`。分析脚本以 SQLite `mode=ro` 打开，保留原数据库。

## 样本

筛选 `BIOG_MAIN.c_dy = 6`，得到 57,474 个独立人物编号；全库人物主表 658,339 行。朝代编码、职业、具体活动年代是不同概念，因此总量称“唐代人物”，不称“唐代诗人总量”。同名人物不按姓名合并。

## 地点与去重

`ADDR_CODES` 可能以不同历史编码保存名称和位置近似相同的地点，例如长安。构建时以“原始中文名称 + 经度四舍五入到两位 + 纬度四舍五入到两位”为展示地点键；坐标缺失时使用原地址编号，不把同名、无坐标地点合并。

地点排行按同一展示地点所关联的人物编号集合计数，而非相加各历史编码人数。导出与详情保留实际贡献记录的历史地址编码。数据库完整地址表仍在源数据库中。

人物档案的地点条目按展示地点、原始类别编码、起始年、终止年分组。合并仅影响展示行数；每行记录数保留，全部人物的原始条数合计为 50,454 条，展示 50,418 个条目。相同地点承担不同类别、或不同年代的经历时，保留为不同条目。

“籍贯”采用 `BIOG_ADDR_DATA.c_addr_type = 1`，覆盖 28,245 人。籍贯与出生地不同；“前住地”“葬地”“死所”等取自 `BIOG_ADDR_CODES` 的原始解释，任职地从专门的任职地点表读取。

地图改用 Natural Earth 1:10m 陆地海岸与河流数据（区域 69°E—139°E、15°N—57°N，保留原顶点及多边形孔洞，坐标五位小数），通过 Leaflet 使用 WGS84/Web Mercator 对齐人物点位。在线层默认使用 Esri World Topographic Map，并提供 OpenStreetMap 标准瓦片选项，按缩放级别请求当前视口，不作离线批量下载；纸本层完全本地加载。在线来源无法取得瓦片时自动回退纸本层，显示实际状态。地图支持拖拽、滚轮/双击缩放、比例尺、历史地点检索定位和标签避让。原始人物经纬度仍取自 CBDB，换用精细底图不提高历史记载本身的定位精度。现代参考地理不表示唐代疆域或历史河道。

不同名称但相近的行政层级可能使用相同坐标，保持独立编码。低缩放隐藏部分文字以避让，地点圆点保持可选；右上角地点检索可定位任何有坐标的展示地点。

## 入仕

原始 `ENTRY_DATA` 对唐代样本有 2,072 行，覆盖 1,824 人。档案按入仕编码与年份分组，保留来源编号与备注。当前快照 2,072 个展示条目，未发生同人物同途径同年份合并。

环图按原始记录数计算，前七类以外汇总为“其他”；人数排行则在每个入仕编码内部按人物编号去重。一个人可有多个途径，因此各类人数之和不等于有记录的总人数。旧输出中 2,068 是各类去重人数之和，不能称作原始记录总数。

## 任职

`POSTED_TO_OFFICE_DATA` 有唐代人物 26,073 人、47,805 条官职记录。档案以任职编号、官职编号和起止年为条目，缺失年份不以外部传记补齐。

任职地点使用 `POSTED_TO_ADDR_DATA`，要求地址编号大于零。共有 27,200 行有效地点记录，覆盖 18,036 人；另有 587 行未指定地址编码，不计入有效任职地分布。它们不影响官职表中的任职记录保存。地点以任职编号和官职编号关联至档案官职经历。

## 个案与缺失值

杜甫 CBDB #3915：15 个地点条目、1 个入仕条目、9 个官职条目、266 条原始社会关系记录。总览仅节选数据库有明确年份的官职，不把缺失年份拼成连续旅行路线。策试记录未载确切年，显示“年未详”。

零年与空年显示未详；索引年独立显示，不冒充出生年。享年沿用数据库值，可能采用传统虚岁，与卒年减出生年不总相等。缺少某类记录不等于人物没有对应经历。

## 重建

在项目根目录运行 `python scripts/build_data.py`。脚本读取 `data/source/cbdb_20260523.sqlite3`，同时生成 JSON 和浏览器可离线加载的 JS 数据文件。首次迁移的 `--legacy` 参数仅用于保留原项目的搜索简繁体映射、地理轮廓与既有姓名检索别名；别名保存为 `assets/search-aliases.json`，以后普通重建同样保留。统计和人物经历全部从 SQLite 重新提取。

课程 PDF / PPT 保留于 `docs/reports/`，里面的旧统计、旧页面名称与截图是历史版本，不作为当前数据口径的依据。
