# 平生功绩：重构与目录整理

类型：本地数字人文研究应用（HTML / CSS / JavaScript / ECharts / Python SQLite）。

## 目标

延续原项目的书卷气与数据展示能力，将人物、地理、入仕、任职与研究方法整理为五个明确入口，项目名统一为「平生功绩」。直接在 `E:\experiments\PingshengGongji` 开发，以新目录实现隔离。

## 数据约定

- 从 `BIOG_MAIN.c_dy = 6` 提取全部唐代人物；统计对象并不等于全部为诗人。
- 每个人物以 CBDB ID 标识，同名异人不合并。
- 地址类别来自 `BIOG_ADDR_CODES`，任职来自独立任职表。
- 同名且坐标一致的历史地址编码按展示地点归并，人数按 ID 集合去重；原编码保留。
- 人物地址按地点、类别与年代归并。条目数与原始记录数分别显示，不丢弃出处。
- 入仕按编码与年归并，未记载保持缺失，不解释为未入仕。

## 交互与视觉

纸白背景、墨色宋体标题、朱红强调、青灰辅助色；大标题与真实地图构成首屏。常驻导航连接「山河」「仕途」「人物」「数据」；地图与排行榜联动；柱状图与三维图切换；搜索支持简繁体、姓名、地点、入仕、人物编号；人物档案分基本信息、地点、入仕、任职；杜甫个案呈现数据库中有年份的履历，不为缺失年份补造路线。
