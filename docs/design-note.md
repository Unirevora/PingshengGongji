# 平生功绩：阅读入口的设计

读人物数据库，难处常在表与表之间。地名、身份和任职各有记录，却不容易一眼看出分布；图表只给比例，又会藏起分母。我想把查询结果整理成一个可阅读的入口，让初步观察和回查依据留在同一处。

初次浏览者可以先看地域与排行；核对结论的人需要数值、来源和分母；继续处理史料的人，则可以回到 JSON 与源码。我按这些阅读任务组织页面，让概览、核验和进一步分析共用一份数据。

地图回答位置，排行方便比较，统计表补足分母和计数单位。把依据放在图旁，是为了减少读者对展示者解释的依赖，也降低回查成本。三维视图保留换个角度观察的趣味，二维入口照顾需要准确比较数值的阅读。

这份数据来自 CBDB 本地快照，按朝代编码“唐”（c_dy = 6）筛得 57,474 人。我整理了籍贯、入仕方式和任职地点的记录，保留人物编号、地名编码、原始条数和出处。数据库将五代另列为 c_dy = 7，本项目没有把两个样本混在一起。

先看宏观分布，再核对具体人物，是这份界面的阅读顺序。分散的表格记录由此有了相互连接的入口，读者可以沿着观察，继续追问数字究竟来自哪里。
